# -FLUJO-DE-CONTROL-PART.-1
Aplicación de consola en C# para calcular el Impuesto Sobre la Renta (ISR) de empleados en República Dominicana usando la tabla oficial de la DGII.

Funcionalidad
- Lee sueldo anual
- Calcula ISR automáticamente
- Indica si está exento o el monto a pagar

Ejecuciones del programa

Caso 1 — Sueldo exento
Caso 2 — ISR 15%
Caso 3 — ISR 20%
Caso 4 — ISR 25%
